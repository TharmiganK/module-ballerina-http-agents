- Log files without `rotation` go through `java.util.logging.FileHandler`: parent directories are not created, there is no `.lck` protection, and `%` in the path is interpreted. Duplicate of ballerina-library#9615.

- Flat-format attribute order follows a fixed internal order, not the configured order. The spec doesn't specify the order, so it is not filed.
- Empty `attributes = []` silently disables access logs. Undocumented, but low value and probably covered by the spec rewrite.
